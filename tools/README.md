# 火球图片点标注工具

## 功能说明

这是一个基于 PySide6 的火球图片点标注工具，提供以下功能：

1. **加载图片**：支持加载常见图片格式（PNG、JPG、JPEG、BMP、GIF）
2. **标注点**：在图片上点击即可标注点，用红色十字显示
3. **显示坐标**：实时显示标注点的坐标（图片坐标系）
4. **计算距离**：自动计算标注点距离参考点(574, 542)的距离（像素单位）
5. **更新标注**：多次点击时，以最后一次标注点为准，自动更新显示

## 使用方法

### 运行工具

```bash
cd tools
python fireball_point_annotator.py
```

### 操作步骤

1. **加载图片**：点击"加载图片"按钮，选择要标注的火球图片
2. **标注点**：在图片上点击任意位置，会在该位置显示红色十字标记
3. **查看信息**：右侧信息面板会显示：
   - 标注点坐标：当前标注点的 (x, y) 坐标
   - 距离参考点：标注点距离参考点(574, 542)的距离（像素）
4. **更新标注**：再次点击图片上的其他位置，会更新标注点和相关信息
5. **清除标注**：点击"清除标注"按钮可以清除当前标注

## 界面说明

- **左侧**：图片显示区域，支持滚动查看大图
- **右侧**：信息显示面板
  - 标注点信息：显示当前标注点的坐标和距离
  - 参考点信息：显示参考点坐标(574, 542)，在图片上用蓝色十字标记

## 标记说明

- **红色十字**：当前标注点
- **蓝色十字**：参考点(574, 542)
- **黄色文字**：标注点坐标，显示在标注点旁边

## 依赖要求

- Python 3.7+
- PySide6

安装依赖：
```bash
pip install PySide6
```

## 注意事项

1. 坐标系统：使用图片坐标系，原点在左上角，x轴向右，y轴向下
2. 距离计算：使用欧几里得距离公式：√((x₁-x₂)² + (y₁-y₂)²)
3. 图片缩放：工具会自动缩放图片以适应窗口大小，但坐标计算基于原始图片尺寸
