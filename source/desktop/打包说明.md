# 火球分析器 - 打包说明

## 概述

本文档说明如何使用PyInstaller将火球分析器打包成可执行文件，支持macOS和Windows系统。

## 环境要求

### 基础环境
- Python 3.9+
- 虚拟环境已激活
- 所有依赖包已安装

### 依赖包
```bash
pip install -r requirements.txt
pip install pyinstaller
```

## 打包脚本

### 1. 简化打包脚本 (推荐)
```bash
python build_simple.py
```
- 适用于当前环境
- 自动检测平台
- 生成单文件可执行程序

### 2. 跨平台打包脚本
```bash
python build_cross_platform.py
```
- 支持macOS、Windows、Linux
- 自动生成spec文件
- 更详细的构建信息

### 3. Windows专用脚本
```bash
python build_windows.py
```
- 专门为Windows系统优化
- 使用Windows路径分隔符
- 生成.exe文件

## 打包结果

### macOS
- 可执行文件: `dist/FireballAnalysis`
- 应用程序包: `dist/FireballAnalysis.app`
- 文件大小: ~93MB

### Windows
- 可执行文件: `dist/FireballAnalysis.exe`
- 文件大小: ~90-100MB

## 使用方法

### 运行应用程序
1. **双击运行**: 直接双击可执行文件
2. **命令行运行**: 在终端/命令提示符中执行
   ```bash
   # macOS
   ./dist/FireballAnalysis
   
   # Windows
   dist\FireballAnalysis.exe
   ```

### 首次运行注意事项
- 首次启动可能需要较长时间（10-30秒）
- 系统可能会显示安全警告，选择"允许"
- 确保有足够的磁盘空间（至少200MB）

## 故障排除

### 常见问题

1. **构建失败**
   - 检查所有依赖包是否已安装
   - 确保虚拟环境已激活
   - 检查必要文件是否存在

2. **运行时错误**
   - 检查系统兼容性
   - 确保有足够的系统资源
   - 查看错误日志

3. **文件过大**
   - 这是正常现象，包含了所有依赖
   - 可以使用`--onedir`模式生成文件夹版本

### 调试模式
如果需要调试，可以使用以下命令：
```bash
pyinstaller --onefile --console app.py
```
`--console`参数会显示控制台窗口，便于查看错误信息。

## 高级配置

### 自定义spec文件
可以手动创建和编辑spec文件来精确控制打包过程：

```python
# 示例spec文件
a = Analysis(
    ['app.py'],
    pathex=['.'],
    binaries=[],
    datas=[
        ('icon/fireball_app_icon.ico', 'icon'),
        ('../*.py', '.'),
        ('../../temp.csv', '.'),
        ('../../images', 'images'),
    ],
    hiddenimports=[
        'PySide6.QtCore',
        'PySide6.QtWidgets',
        'matplotlib.backends.backend_qt5agg',
        # ... 其他隐藏导入
    ],
    hookspath=[],
    hooksconfig={},
    runtime_hooks=[],
    excludes=[],
    win_no_prefer_redirects=False,
    win_private_assemblies=False,
    cipher=None,
    noarchive=False,
)
```

### 优化选项
- `--strip`: 去除调试信息，减小文件大小
- `--upx-dir`: 使用UPX压缩，进一步减小文件大小
- `--exclude-module`: 排除不需要的模块
