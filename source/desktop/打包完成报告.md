## 🚀 使用方法

### 运行应用程序
```bash
# macOS
./dist/FireballAnalysis

# Windows
dist\FireballAnalysis.exe
```

### 首次运行
- 首次启动需要10-30秒
- 系统可能显示安全警告，选择"允许"
- 确保有足够的磁盘空间（至少200MB）

## 📋 系统要求

- **Windows**: Windows 7+ (64位)
