# 爆炸火球分析系统 - 图标使用说明

## 🎨 生成的图标文件

### 推荐使用图标
- **`fireball_app_icon.ico`** - 主要应用图标（推荐）
- **`fireball_app_icon.png`** - PNG格式版本

### 其他风格图标
- **`fireball_professional_icon.ico`** - 专业风格图标
- **`fireball_modern_icon.ico`** - 现代风格图标
- **`fireball_minimal_icon.ico`** - 简约风格图标

## 🔥 图标设计特点

### 主要图标 (fireball_app_icon)
- **火球核心**: 金色渐变，代表爆炸火球
- **火焰效果**: 多层橙色到红色渐变，模拟真实火焰
- **数据分析元素**: 蓝色数据点和连接线，表示分析功能
- **温度曲线**: 橙色曲线，表示温度分析
- **半径曲线**: 金色曲线，表示半径分析
- **背景**: 深蓝色渐变，专业感强

### 设计理念
1. **功能性**: 图标直接体现了火球分析的核心功能
2. **专业性**: 深色背景和精确的几何图形
3. **识别性**: 独特的火球形状，易于识别
4. **现代感**: 渐变色彩和简洁设计

## 📦 在打包中使用图标

### 方法1: 使用PyInstaller
```bash
pyinstaller --icon=icon/fireball_app_icon.ico --onefile --windowed app.py
```

### 方法2: 使用构建脚本
```bash
python build_with_icon.py
```

### 方法3: 在spec文件中指定
```python
exe = EXE(
    # ... 其他参数 ...
    icon='icon/fireball_app_icon.ico',
    # ... 其他参数 ...
)
```

## 🖥️ 不同平台的图标格式

### Windows
- 使用 `.ico` 格式
- 支持多尺寸 (16x16, 32x32, 48x48, 64x64, 128x128, 256x256)
- 推荐: `fireball_app_icon.ico`

### macOS
- 使用 `.icns` 格式 (需要转换)
- 推荐尺寸: 512x512, 256x256, 128x128, 64x64, 32x32, 16x16
- 可以使用PNG格式: `fireball_app_icon.png`

### Linux
- 使用 `.png` 格式
- 推荐尺寸: 512x512, 256x256, 128x128, 64x64, 32x32, 16x16
- 推荐: `fireball_app_icon.png`

## 🎯 图标应用场景

### 桌面快捷方式
- Windows: 右键 -> 属性 -> 更改图标
- macOS: 右键 -> 显示简介 -> 拖拽图标
- Linux: 右键 -> 属性 -> 图标

### 应用程序窗口
- 在PySide6中设置窗口图标:
```python
app.setWindowIcon(QIcon('icon/fireball_app_icon.png'))
```

### 安装程序
- 在安装程序中设置应用程序图标
- 在开始菜单中显示图标

## 🔧 自定义图标

如果需要修改图标，可以：

1. **运行图标生成脚本**:
```bash
cd icon
python generate_icon.py          # 生成基础图标
python create_professional_icon.py  # 生成专业图标
```

2. **修改设计参数**:
   - 在脚本中调整颜色、大小、形状
   - 添加或删除设计元素

3. **重新生成**:
   - 运行脚本重新生成图标文件
   - 重新打包应用程序
