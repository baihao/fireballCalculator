# 桌面程序菜单栏 UI 说明

本文档描述主窗口菜单栏（**文件**、**视图**）的行为与代码位置，便于后续维护与测试。

## 1. 视图菜单

| 菜单项 | 行为 |
|--------|------|
| **机器视觉** | 切换到主界面「机器视觉」标签页（与 `QTabWidget` 第一个 tab 一致）。 |
| **机器学习** | 切换到「机器学习」标签页。 |
| **显示侧边栏** | 可勾选；控制左侧侧边栏显隐。 |
| **切换全屏** | 全屏 / 还原窗口（系统标准全屏快捷键，如 F11）。 |

- 上述两项标签切换在菜单中为**互斥勾选**，并与**点击 tab 标题**切换保持同步。
- **默认视图**：应用启动后当前 tab 为「机器视觉」（`tab` 索引 0），菜单中「机器视觉」为选中状态。

**实现文件**：`source/desktop/menu/view_menu.py`（函数 `setup_view_menu`）。

---

## 2. 文件菜单

「文件」菜单中**与数据导入相关的条目随当前视图变化**（由 `tab_widget.currentIndex` 驱动）。

### 2.1 当前为「机器视觉」时

显示以下三项，行为与 **机器视觉** 侧边栏 **「数据源」** 分组中对应按钮一致（非「机器学习」页）：

| 菜单项 | 对应逻辑 |
|--------|----------|
| **导入火球图像序列** | `ExtractTab.select_image_sequence_folder`（同「导入火球图像序列」按钮）。 |
| **导入爆炸序列文件** | `ExtractTab.select_sequence_folder`（同「导入爆炸序列文件」按钮）。 |
| **导入火球温度序列** | `ExtractTab.select_temperature_sequence`（同「导入火球温度时间序列」按钮，菜单文案略简）。 |

### 2.2 当前为「机器学习」时

| 菜单项 | 对应逻辑 |
|--------|----------|
| **导入训练文件** | `ModelTab.select_training_files`（同「选择训练文件」按钮）。 |

### 2.3 始终显示

| 菜单项 | 行为 |
|--------|------|
| **退出** | 关闭主窗口；使用 `QAction.MenuRole.NoRole`，**不**合并到 macOS 的「应用」菜单。 |

**实现文件**：`source/desktop/menu/file_menu.py`（函数 `setup_file_menu`）。

---

## 3. 模块划分

| 文件 | 职责 |
|------|------|
| `source/desktop/menu/app_menu_bar.py` | 创建 `QMenuBar`，添加「文件」「视图」子菜单并调用下方 setup。 |
| `source/desktop/menu/file_menu.py` | **仅**「文件」菜单逻辑。 |
| `source/desktop/menu/view_menu.py` | **仅**「视图」菜单逻辑。 |

主窗口装配入口：`FireballAnalysisApp.init_ui` 中调用 `setup_application_menu(self)`（见 `source/desktop/framework.py`）。

---

## 4. 需求勘误说明

原始需求中曾写「机器学习页面中导入数据源 group」——与当前界面结构不符。实际 **三个序列/温度导入** 位于 **机器视觉** 页的侧边栏 **「数据源」**；**训练文件** 位于 **机器学习** 页的 **「模型训练」** 区域。实现已按界面真实情况绑定，并以本节与第 2 节为准。

---

## 5. 平台说明（简要）

- **Windows**：菜单栏位于窗口标题栏下方，为典型桌面应用布局。
- **macOS**：菜单栏位于屏幕顶部；「退出」仍保留在「文件」菜单内（见 2.3）。

全局深色样式可能影响菜单外观，与纯系统默认配色或有差异，属主题层面问题，不改变本文所述交互逻辑。
