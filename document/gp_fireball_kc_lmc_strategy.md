# 火球拖曳参数代理模型：\(K\) 与 \(C\) **分模型**单输出 GP + 常数 \(B\) 策略

> 公式使用 `$…$`（行内）与 `$$…$$`（独立行），请在支持 **MathJax / KaTeX** 的预览中查看。

本文档取代并合并原 `gp_diameter_fit_surrogate_analysis.md`、`gp_model_k_plateau_and_variance_notes.md`、`gp_and_mogp_intro.md` 中与**本仓库默认建模策略**相关的讨论，给出**仅由输入 \(\mathbf{x}\)**（当量、含铝量）通过**高斯过程**拟合 **\(K\)** 与 **\(C\)** 的完整算法说明与实现要点：**\(K\)**、**\(C\)** 各用 **一个独立的单输出 GP** 分别学习与推理，**不在同一模型中一次性联合输出 \((K,C)\)**（即不采用共享潜过程的 MOGP/LMC 作为默认路径）；**\(B\)** 不参与 GP，取训练数据集中 **\(B\) 的样本均值**作为全局预测值。

---

## 1. 问题设定与符号

### 1.1 拖曳曲线与参数

火球直径随时间（毫秒）采用拖曳形式：

$$
D(t) = K\bigl(1 - B\,e^{-C t^2}\bigr),\quad C>0,\ B\ \text{在}\ (0,1]\ \text{内有意义}.
$$

训练样本来自 JSON：每条在 `drag_fit.success == true` 时给出标量 **\(K,B,C\)**，输入在 `parameters` 中。

### 1.2 输入与输出（本策略）

- **输入**（二维，**物理单位、不做仿射归一化**）：

$$
\mathbf{x} = (x_0,\,x_1)^\top = (\text{当量}\ [\mathrm{kg}],\ \text{含铝量}\ [\%])^\top.
$$

典型范围：当量约 \(1\sim160\)，含铝量约 \(20\sim40\)（以实际数据为准）。

- **由 GP 预测**：**\(K(\mathbf{x})\)** 与 **\(C(\mathbf{x})\)** 由 **两个互不耦合的单输出高斯过程** 分别给出边缘预测；**不**将 \((K,C)^\top\) 作为同一向量值 MOGP 的一次性联合输出（实现上为两次 `ExactGP` 式训练与两次预测后再组装）。

- **常数预测**：

$$
\bar B = \frac{1}{n}\sum_{i=1}^n B^{(i)},
$$

其中 \(\{B^{(i)}\}\) 为训练集中所有有效样本的 \(B\)。对新输入 \(\mathbf{x}_{\ast}\)：

$$
\hat B(\mathbf{x}_{\ast}) \equiv \bar B.
$$

**动机**：数据与实践中 **\(B\)** 变化幅度小、与 \(\mathbf{x}\) 的规律性弱，用常数近似可降低模型复杂度；**\(K\)** 与 **\(C\)** 随工况变化，由 **各自独立**的 GP 分别建模。**分模型**可避免多输出核（如 LMC）中 **\(K\) 与 \(C\)** 共享归纳偏置时，**数量级或辨识度差异较大**的一方（常见为 **\(C\)**）被另一方主导，便于在测试点上分别还原边缘行为。

---

## 2. 核与输入侧超参数（原坐标 + 按维长度尺度）

**不对 \(\mathbf{x}\) 做逐维标准化**（不保存 `input_standardization` 对 \(X\) 的 \(\mu,\sigma\) 变换）。量纲差异通过 **ARD 风格的平方指数（RBF/SE）核** 中**各维独立长度尺度**吸收。

### 2.1 标量输出核（**\(K\)** 模型与 **\(C\)** 模型各一套超参）

**\(K\)** 与 **\(C\)** **各用**一个单输出 GP。记 **第 \(m\in\{K,C\}\) 个** GP 的信号方差 \(\sigma_m^2 > 0\)，长度尺度 \(\ell_{m,0},\ell_{m,1} > 0\) 分别对应 \(x_0\)（当量）、\(x_1\)（含铝量）。平方指数核为：

$$
k_m(\mathbf{x},\mathbf{x}') = \sigma_m^2 \exp\!\Big(-\tfrac12 \sum_{d=0}^{1} \frac{(x_d-x_d')^2}{\ell_{m,d}^2}\Big).
$$

**待估输入侧超参数**可记为 \(\boldsymbol{\theta}_{x}^{(m)} = (\sigma_m,\ell_{m,0},\ell_{m,1})^\top\)（两模型**独立**优化，一般**不**强行共享 \(\ell\)）。

**说明**：当量跨度远大于含铝量时，**各模型**优化得到的 \(\ell_{m,0}\) 与 \(\ell_{m,1}\) **数值量级可差很多**，这是预期行为；关键是 **\(\ell_{m,d}\) 与原始 \(x_d\) 单位一致**。**不对 \(\mathbf{x}\) 做逐维标准化**。

---

## 3. 输出侧：不标准化 \(K\) 与 \(C\)

训练标签在**物理量纲**下分别用于两个模型：

$$
y_K^{(i)} = K^{(i)},\quad y_C^{(i)} = C^{(i)},\quad i=1,\ldots,n.
$$

**不对 \(K\)、\(C\) 列做减均值或除标准差**。两模型 **各自**学习噪声方差 \(\tau_K^2,\tau_C^2\)，避免多输出结构下弱信号输出被牺牲。**预测接口**分别输出 \(\hat K\) 与 \(\hat C\) 的均值与方差（物理单位），无需逆变换。

---

## 4. 建模选择：两个独立单输出 GP（**默认**）

### 4.1 为何默认**不**用联合 MOGP 一次性输出 \((K,C)\)

同一 JSON 上联合拟合的 **\(K\)** 与 **\(C\)** 在统计上**可相关**，但**本策略默认**采用 **两个独立 GP**，原因包括：

- **边际可辨识**：**\(K\)** 与 **\(C\)** 数量级与沿 \(\mathbf{x}\) 的变化幅度往往不同；多输出核（LMC 等）共享输入光滑性时，易出现 **一任务主导边际似然**、另一任务在后验均值上**接近常数或形状失真**。
- **实现与调参**：独立模型对应 **两个**标量 **`ExactGP` + `GaussianLikelihood`**，训练、重启选优、长度尺度初值等可 **按任务分别**配置与诊断。
- **代价**：**不再**显式建模 **\(K\)**–**\(C\)** 的观测相关；若需 **联合不确定性带** 绘制 \(D(t)\) 云图，默认采用 **\(K,C\) 独立**的边缘高斯近似（独立采样），**严格联合**需回到 MOGP 或 copula 等扩展（非默认）。

### 4.2 与 MOGP / LMC 的关系（对照、非默认）

历史与文献中的 **MOGP、ICM、LMC**（\(Q=2\)）将输出向量 \(\mathbf{y}=(K,C)^\top\) **一次**条件于同一组训练数据，可编码跨输出相关。**本仓库策略文档以「双单任务 GP」为默认契约**；若实验上联合模型在验证集上系统性更优，可在**独立分支或配置**中保留 MOGP 作为对照（参见 Alvarez et al. 综述）。**产品级接口**仍对外给出 **\((\hat K,\hat B,\hat C)\)**：\(\hat B=\bar B\)，\(\hat K,\hat C\) 由**两次推理**拼装，**非**单次前向返回二维向量。

## 5. 观测模型、训练目标与预测

### 5.1 有限维记号（**双模型**）

训练集 \(\{\mathbf{x}_i,\,K^{(i)},\,C^{(i)}\}_{i=1}^n\)。**\(K\) 模型**只看 \(\mathbf{y}_K = (K^{(1)},\ldots,K^{(n)})^\top\)；**\(C\) 模型**只看 \(\mathbf{y}_C = (C^{(1)},\ldots,C^{(n)})^\top\)。潜函数记为 \(f_K(\mathbf{x})\)、\(f_C(\mathbf{x})\)，各加独立高斯观测噪声 \(\tau_K^2,\tau_C^2\)，超参分别记为 \(\boldsymbol{\phi}_K,\boldsymbol{\phi}_C\)。

### 5.2 型-II 极大似然（边际似然）

对 **\(m\in\{K,C\}\)**，在高斯假设下：

$$
\log p(\mathbf{y}_m\mid \mathbf{X},\boldsymbol{\phi}_m)
= -\tfrac{n}{2}\log(2\pi)
 -\tfrac{1}{2}\log\det\boldsymbol{\Sigma}_{y,m}(\boldsymbol{\phi}_m)
 -\tfrac{1}{2}\mathbf{y}_m^\top \boldsymbol{\Sigma}_{y,m}(\boldsymbol{\phi}_m)^{-1}\mathbf{y}_m.
$$

**训练**：对 **\(K\)** 与 **\(C\)** **分别**用梯度法（如 Adam）**最大化**上式（实现上两个 `ExactMarginalLogLikelihood` + 两套优化，或顺序训练）。可选用**不同**的随机重启种子与长度尺度初值策略（见工程文档）。

### 5.3 新输入上的预测（边缘后验，独立）

给定 \(\hat{\boldsymbol{\phi}}_K,\hat{\boldsymbol{\phi}}_C\)，对新点 \(\mathbf{x}_{\ast}\)：

$$
f_K(\mathbf{x}_{\ast}) \mid \mathbf{y}_K,\mathbf{X} \sim \mathcal{N}(\mu_{\ast}^{K},\,(\sigma_{\ast}^{K})^2),\qquad
f_C(\mathbf{x}_{\ast}) \mid \mathbf{y}_C,\mathbf{X} \sim \mathcal{N}(\mu_{\ast}^{C},\,(\sigma_{\ast}^{C})^2.
$$

若报告**下一次观测**，在各自方差上加上相应似然噪声。**联合**画 \(D(t)\) 云图时，若无 MOGP，**默认**取 **\(K,C\) 独立** 的边缘：\((\hat K,\hat C)\) 可 **独立**从各自一维高斯采样；这**忽略**了 \(K\)–\(C\) 相关，与 §4.1 的建模取舍一致。

### 5.4 与单任务 GP 的对应

| 概念 | 单输出 GP | 本策略（两次单输出） |
|------|-----------|---------------------|
| 训练目标 | \(\log p(\mathbf{y}\mid\mathbf{X},\boldsymbol{\phi})\) | **\(K\)**、**\(C\)** **各一份**同形式目标 |
| 预测 | 标量 \(\mu_{\ast},\sigma_{\ast}\) | **两次**：\((\mu_{\ast}^{K},(\sigma_{\ast}^{K})^2)\) 与 \((\mu_{\ast}^{C},(\sigma_{\ast}^{C})^2)\) |

## 6. 端到端算法流程（功能实现）

以下步骤对应「从训练目录 JSON 到给出新配方的 \(\hat K,\hat B,\hat C\)」。

### 6.1 数据加载

1. 扫描 `training_data/*.json`（排除无 `drag_fit` 或 `success!=true` 的文件）。
2. 解析每条：\(x_0=\) `equivalent`，\(x_1=\) `al_percent`；\(K,B,C\) 来自 `drag_fit`。
3. 构造 \(\mathbf{X}\in\mathbb{R}^{n\times 2}\)（**原单位**），\(\mathbf{Y}_{KC}\in\mathbb{R}^{n\times 2}\)（**仅 \(K,C\) 列**）。
4. 计算 \(\bar B = \mathrm{mean}(\{B^{(i)}\})\)，**持久化**到训练产物（如超参数 JSON 字段 `b_mean`）。

### 6.2 模型配置

1. **模型 A（\(K\)）**：`ExactGP` + **标量** `GaussianLikelihood`；`ConstantMean`；`ScaleKernel(RBFKernel(ard_num_dims=2))`（或等价 RBF+ARD 写法）。
2. **模型 B（\(C\)）**：与上**结构相同**、**参数不共享**（两套 \(\sigma_m,\ell_{m,0},\ell_{m,1}\)、噪声 \(\tau_m^2\)）。
3. **关闭**：对 **\(X\)** 的 `StandardScaler` 式变换；对 **\(Y\)** 的按列标准化。
4. **不**将 \((K,C)\) 并入单一 **`MultitaskGaussianLikelihood`** 作为**默认**路径。

### 6.3 训练

1. 对 **\(K\)**：`mll_K = ExactMarginalLogLikelihood(likelihood_K, model_K)`，最小化 `-mll_K`。
2. 对 **\(C\)**：同理 `mll_C`。
3. 将 \(\hat{\boldsymbol{\phi}}_K,\hat{\boldsymbol{\phi}}_C\)（及各自 `state_dict`）、**训练用 \(\mathbf{X}\)**、**\(\mathbf{Y}_{KC}\)**、**\(\bar B\)** 写入 **`trained_hyperparams.json`**。**落盘契约**可为**嵌套** `torch.model_K` / `torch.model_C`（或等价键名），详见 `fireball_gp_mogp_module_design.md` §6.3；实现尚未拆分时以代码为准。

### 6.4 推理

1. 读入产物，分别重建 **\(K\)** 与 **\(C\)** 的 `ExactGP` + 似然。
2. 输入 **\(\mathbf{x}_{\ast}\)（原单位）**，**分别**前向：得 \(\hat K\) 与 **\(\hat C\)** 的均值与边际方差（**非**单张量输出的第二维）。
3. 拼装：

$$
\hat B = \bar B,\quad \hat K,\hat C\ \text{来自两次独立 GP 预测}.
$$

4. 将 \((\hat K,\hat B,\hat C)\) 代入 \(D(t)\) 供 `curve_plot` 或应用层使用。

### 6.5 与直径曲线模块的衔接

`curve_plot` 仍使用完整三元组 \((K,B,C)\)；**\(K,C\)** 由 **两次** GP 预测值拼装，**\(B\)** 由产物中的 **`b_mean`** 注入。

```json
{
  "K": 10.2,
  "B": 0.5617,
  "C": 0.00042,
  "equivalent": 20.0,
  "al_percent": 40.0,
  "B_source": "train_mean"
}
```

## 7. 验证、风险与工程注意

1. **交叉验证**：LOO 或重复 K 折；关注 **\(K,C\)** 的标量误差与 **\(D(t)\)** 是否落在合理物理范围。
2. **约束**：若 **\(C\le 0\)** 或 **\(B\notin(0,1]\)** 的预测出现，应在后处理中裁剪或采用对数/逻辑变换在**潜空间**再建模（本策略未默认启用变换域）。
3. **外推**：\(\mathbf{x}_{\ast}\) 落在训练凸包外时，后验方差增大；应告警或限制自动使用。
4. **小样本**：**双模型**参数量仍可能偏多；可对两任务**分别**监视边际似然与验证误差，并分别做重启选优。
5. **仿真与实验混合**：可对不同来源样本设不同观测噪声方差（异方差似然），参见原可行性分析中的加权思路；本文不展开。

## 8. 与历史工程记录的差异（供维护者理解）

- **旧版**曾在输入上采用标准化并在 **\(K,B,C\) 三输出**上做 MOGP；曾出现 **\(K\)** 沿当量「平台化」、**\(C\)** 后验变化过小等现象，部分与**长度尺度**及**多输出共享结构**有关。中间形态为 **原坐标 + ARD** 下 **\(K,C\)** 的 **联合 MOGP（LMC \(Q=2\)）**。**当前策略默认**改为 **\(K\)、\(C\) 各一独立单输出 GP**，**不**一次性联合输出 \((K,C)\)，以改善**边缘**可辨识与测试点还原；**\(B\)** 仍为训练集均值。
- **方差**：区分 **潜函数 \(f\)** 与 **观测 \(y\)** 的预测方差；**双单任务**模型下 **\(K\)**、**\(C\)** 边缘方差**各自**解释，**不**含二者协方差。出图约定可与 CLI/CSV 文档齐：**阴影可用 \(f\)** 的 \(\pm 2\sigma\)（每条任务分别）。
