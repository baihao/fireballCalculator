# 基于高斯过程的火球直径拖曳拟合参数预测：可行性、增量学习与异源数据融合

> 数学公式使用 `$…$`（行内）与 `$$…$$`（独立行），请在支持 **MathJax / KaTeX** 的预览中查看（如 VS Code 安装 Markdown+Math、或 Typora、或导出 HTML）。

## 1. 问题与数据形式

### 1.1 目标

- **输入**：炸药当量（kg TNT 当量）、含铝量（%）等少量可控/可测参数，可记为向量 $\mathbf{x} \in \mathbb{R}^d$（当前 $d=2$ 或可扩展）。
- **输出**：火球直径随时间曲线经拖曳函数  
  $$
  D(t) = K\bigl(1 - B\,e^{-C t^2}\bigr)
  $$  
  拟合得到的参数 $(K, B, C)$，可记为 $\mathbf{y} \in \mathbb{R}^3$（或对 $B,C$ 做约束变换后的等价参数化）。

### 1.2 训练数据

- **真实实验**：每个样本为 $(\mathbf{x}^{(i)}, K^{(i)}, B^{(i)}, C^{(i)})$，噪声来源包括实验条件、测量、以及「先拟合曲线再反演参数」的误差传递。
- **物理仿真**：同构的 $(\mathbf{x}, K, B, C)$，但由数值模型得到；系统偏差与实验不同，且通常更光滑、不确定性结构不同。

### 1.3 建模策略（用户拟定）

在样本量很小的前提下，用**高斯过程（Gaussian Process, GP）**建立  
$$
\mathbf{x} \mapsto (K, B, C)
$$  
的回归关系；新实验/新仿真到来时**更新模型**；仿真样本以**低于真实实验的权重**参与训练。

下文从**可行性**、**增量 GP**、**加权/多保真**三方面论证，并指出主要风险与验证要点。

---

## 2. 用 GP 联系 (当量, 含铝量) 与 (K, B, C) 的可行性

### 2.1 合理性

- **小样本、低维输入**：$d=2$ 时，经典 GP 的「维度灾难」压力较小；核函数可表达「相近配方 → 相近拟合参数」的平滑假设，与物理直觉一致。
- **多输出**：$(K,B,C)$ 是三维向量。可行做法包括：
  - **独立 GP**：对 $K,B,C$ 各建一个 GP（实现简单，忽略输出间相关）；
  - **多输出 GP / 线性模型核（LMC）**：显式建模 $K,B,C$ 之间的相关，在样本极少时若先验设得过强可能过拟合，但理论上更一致。
- **与曲线预测的关系**：若新点预测得到 $(\hat K,\hat B,\hat C)$，则直径曲线由解析式给出，无需再对整条 $D(t)$ 做 GP，**计算与可解释性**较好。

### 2.2 局限与需注意点

- **参数化非唯一性 / 约束**：$B,C$ 往往有物理或数值可行域（如 $B\in(0,1]$、$C>0$）。建议在**变换空间**回归，例如  
  $B = \sigma(\tilde B)$、$C = \mathrm{softplus}(\tilde C)$，  
  对 GP 在 $(\tilde B, \tilde C)$ 上建模，再映射回原空间，避免无意义外推。
- **误差传递**：$(K,B,C)$ 来自对离散 $D(t)$ 的拟合，其不确定性**异质且相关**；理想做法是把拟合的**后验或协方差**带入二级模型（见第 5 节加权思路）；小样本时至少应对残差大的点加大噪声方差。
- **外推**：GP 在训练凸包**之外**预测方差会变大，但均值仍可能过于自信（取决于核与超参）。小样本下**主动在边界配方补点**或采用**保守外推**（t 过程、增大噪声先验）更稳妥。

**结论**：在**低维输入 + 显式参数约束/变换**的前提下，用 GP 学习 $\mathbf{x}\to(K,B,C)$ **在工程上是可行且常见**的；主要风险在**外推**与**忽略拟合误差结构**，需用验证与不确定性展示来约束使用范围。

## 3. 小样本下选择 GP 的合理性（简要）

| 方面 | 说明 |
|------|------|
| 数据需求 | 相比深度网络，GP 在 $n$ 很小时更不易「空转」，且天然给出预测方差。 |
| 归纳偏置 | 核长度尺度可编码「当量/含铝量变化多快会影响 $K,B,C$」；可通过多核或 ARD 自动尺度。 |
| 可更新性 | 存在从精确到近似的多种**序贯更新**路径（下一节），适合「陆续做实验」的场景。 |

深度 GP、神经网络等可作为样本增多后的升级路线，但不否定当前阶段 GP 作为**基线与不确定性量化工具**的价值。

## 4. 新数据到来时：可迭代 / 序贯的高斯过程回归方法

「迭代」在文献中常对应：**在线学习、序贯更新、稀疏化近似**，而非重新从零训练不可行。

### 4.1 精确 GP 的秩一更新（数据量仍小时）

若采用**共轭指数噪声模型**（回归中常见为高斯似然），新样本 $(\mathbf{x}_\mathrm{new}, \mathbf{y}_\mathrm{new})$ 加入后，对固定超参数而言，可用 **Sherman–Morrison–Woodbury** 或 Cholesky **秩一更新**更新 $(K+\sigma^2 I)^{-1}$ 或分解，复杂度约 $O(n^2)$ 每次新点。  
- **优点**：数学上等价于全量重算，适合 $n$ 仍较小（如几十以内）。  
- **缺点**：$n$ 增大后 $O(n^3)$ 训练、$O(n^2)$ 存储成为瓶颈。

### 4.2 超参数的「迭代」：经验贝叶斯 / 边际似然优化

每批新数据到达后，可**重新优化**边际似然（或对超参做 MCMC）。这不是「闭式递推」，但是**标准实践**：  
- 新数据少时：可在旧超参附近**warm-start** 微调，减少不稳定。  
- 若坚持严格在线且避免重复优化：可考虑**稀疏变分 GP（SVGP）**等，用小批梯度更新变分参数与部分超参（见下）。

### 4.3 稀疏与伪输入：FITC / VFE / SVGP

当 $n$ 增长，用 **$m\ll n$ 个诱导点（inducing points）** 近似完整 GP：

- **FITC / PITC**：早期稀疏近似，实现相对直接。  
- **VFE（变分自由能）**、**SVGP**：变分推断，支持**小批量（mini-batch）**与**随机梯度**，适合「流式」追加数据、反复更新。  

**含义**：用户所说的「产生新数据就更新 GP」在工程上常落地为：**SVGP + 周期性或每批新实验后的变分/超参更新**，而非永远保留全部历史点的精确核矩阵。

### 4.4 其他相关方向（可选）

- **递归 GP / 状态空间近似**：一维输入时间序列上常见；对二维配方空间不总是首选。  
- **Student-t 过程**：更厚尾，对异常点更稳健，更新公式比 GP 复杂，可作为稳健化扩展。  

**结论**：**小 $n$**：精确 GP + Cholesky 重算或秩一更新即可；**$n$ 增大或流式**：**诱导点 + 变分（SVGP）**是主流可迭代方案；**超参**建议随数据批次**再优化或微调**，并 warm-start。

## 5. 真实实验与物理仿真：降低仿真权重的常用方法

目标：同一 GP（或多输出 GP）同时吃**高可信度实验**与**低可信度仿真**，但**仿真不应支配**边界与全局形状。

### 5.1 异方差高斯噪声（最直接）

对每个样本 $i$ 设观测噪声方差 $\sigma_i^2$（或对仿真统一 $\sigma_\mathrm{sim}^2 \gg \sigma_\mathrm{exp}^2$）。  
- **实现**：加权最小二乘视角等价于对仿真点赋予**更大噪声** → 核回归中该点对后验的「拉力」变弱。  
- **注意**：$\sigma_i$ 需可解释（例如由仿真网格收敛性、或与实验对比的残差标定），避免纯手调无界。

### 5.2 仿真作为「有偏」观测：常数偏移或残差建模（多保真简化版）

- **残差学习**：令 $y = y_\mathrm{exp}$ 为真值，仿真给出 $y_\mathrm{sim}(\mathbf{x})$；建模  
  $$
  y_\mathrm{exp}(\mathbf{x}) = f(\mathbf{x}) + \epsilon,\quad
  y_\mathrm{sim}(\mathbf{x}) = f(\mathbf{x}) + \delta(\mathbf{x}) + \epsilon'
  $$  
  其中 $f$ 为共享的「物理一致」部分，$\delta$ 为仿真偏差（可用另一小 GP 或简单参数）。  
- **效果**：实验点主要约束 $f$，仿真在**不与实验冲突**处填充形状，权重通过 $\epsilon,\epsilon'$ 与 $\delta$ 的先验调节。

### 5.3 线性模型共区域化（LMC）与多保真核

将「数据源」（实验/仿真）视为**第二个输入维**或**多输出通道**，用 **coregionalization** 建模通道间相关；再通过噪声结构或核幅度使**实验通道更窄**。适合理论完备但**标定**需要更多数据或专家假设。

### 5.4 样本复制与加权（需谨慎）

简单地对仿真点**重复复制**以「伪增权」在概率上**不等价**于正确噪声模型，易导致校准错误的置信区间；更推荐**显式 $\sigma_i^2$** 或**多保真构造**。

**结论**：**优先推荐**：对 $K,B,C$ 各任务（或联合输出）使用 **输入相关或分组相关的噪声方差**（实验小、仿真大）；有精力时再上 **残差/多保真 GP** 分离系统偏差。

## 6. 验证、风险与使用建议

1. **交叉验证**：Leave-one-out 或重复 K-fold（样本极少时以 LOO-CV + 可视化预测区间为主）。  
2. **物理约束**：预测 $(\hat K,\hat B,\hat C)$ 后检查 $D(t)$ 单调性、渐近值与实验量级是否合理。  
3. **外推告警**：当 $(\mathrm{当量}, \mathrm{含铝})$ 落在训练点凸包外时，应**放大报告不确定性**或拒绝自动推荐。  
4. **仿真标定**：若有部分配方同时存在实验与仿真，可用其差异估计 $\delta$ 或 $\sigma_\mathrm{sim}$，使权重有数据支撑而非纯主观。  
5. **版本化**：每次更新 GP（超参或诱导点）后保存**数据版本、核与超参、代码 commit**，便于复现实验与回溯。

---

## 7. 总结

| 议题 | 结论 |
|------|------|
| GP 预测 $(K,B,C)$ | **可行**；建议在变换域建模并处理约束；注意拟合误差与外推。 |
| 小样本 | GP **合理**，优于盲目上大模型；可先独立三输出 GP 再考虑多输出核。 |
| 迭代更新 | 小 $n$：**精确 GP + 重算/秩一更新**；大 $n$ 或流式：**诱导点 + SVGP 小批更新**；超参建议**批次微调**。 |
| 仿真降权 | **推荐异方差噪声**（仿真大方差）；进阶用**残差/多保真**或 coregionalization。 |

该路线与「样本少、陆续积累、实验贵、仿真廉」的设定一致；**可行性高**，**合理性**取决于噪声建模、参数化约束与验证流程是否到位。后续若样本增至数百上千，可再评估稀疏 GP 的诱导点数目或切换到深度核/神经网络并保留 GP 层作为不确定性模块。
